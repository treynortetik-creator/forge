# Sprite library

Transparent WebP. `sprites/` holds the approved sizes used by the reference cut; `large/` holds the same art up to 1000 px
for close-ups (blank = no larger version is worth having). No words, no logos, no faces on people. Picture of all of
them: `../contact-sheet.webp`. All were generated with a command-line image tool from the prompts in `../prompts/`.
