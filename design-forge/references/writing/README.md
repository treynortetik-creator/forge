# Bundled craft notes

Working notes the skills read from. Each carries its own `source:` frontmatter naming where it came
from, and every source is credited in `../../THIRD-PARTY-NOTICES.md`.

Most of these are **summaries written in this repository's own words** of publicly posted craft
material — largely Jason Hamilton / The Nerdy Novelist's videos and n8n automations, plus Wulf Moon's
framework and Browne & King's *Self-Editing for Fiction Writers*. Ideas are not copyrightable;
restating a method with attribution is ordinary note-taking.

**`style-guide-prompt.md` was reworded on 2026-08-14** so it carries the *method* — two-stage register
sampling, then a thirteen-dimension instruction sheet — in this repository's own wording rather than
reproducing the original prompt text.

**`banned-words.md`** is the working blocklist the de-sloppifier treats as a hard constraint in Pass 3.
Its vocabulary derives from the Story Hacker writing system and from model-comparison line-edit
sessions, and it has been extended here since. Credited in NOTICES.md.

If you are one of the creators credited and want a note reworded or removed, open an issue and it goes
the same day.
